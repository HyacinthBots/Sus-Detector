## About

Sus Detector is a specialised Discord bot that keeps watch over a specific channel that is used to trap spambots and bans any account that sends a message inside it.

## Usage

**If you're looking to add Sus-Detector to your server, you don't need any of this and can simply click [this link](https://discord.com/oauth2/authorize?client_id=1461718494361161789&permissions=26628&integration_type=0&scope=bot+applications.commands).**

If you need additional instruction using up the public instance of Lily, try our [usage guide](https://github.com/HyacinthBots/LilyBot/blob/main/docs/usage-guide.md).

If you're looking to set up a development environment for Lily, try our [development guide](https://github.com/HyacinthBots/LilyBot/blob/main/docs/development-guide.md).


### Tooling

Lily makes use of the following tools and frameworks.

* [Kord](https://github.com/kordlib/kord), the Kotlin API for Discord.
* [KordEx](https://github.com/Kord-Extensions/kord-extensions), an integrated commands and extensions framework for Kord.
* [MongoDB](https://www.mongodb.com/)
  to manage the database.
* [Logback](https://github.com/qos-ch/logback), a library that makes logging prettier
* [Kotlin Logging](https://github.com/oashai/kotlin-logging), a lightweight logging that wraps SLF4J with kotlin extensions
* [detekt](https://detekt.dev/index.html), a static code analysis tool for the Kotlin programming language. This helps us keep our code clean and nicely formatted.
